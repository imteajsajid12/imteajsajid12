<details>
<summary>🛠️ <b>Enable the 🐍 commit-chart snake</b> (click to expand)</summary>

<br>

Create `.github/workflows/snake.yml` in this repo and paste:

```yaml
name: Generate contribution snake
on:
  schedule: [{ cron: "0 */12 * * *" }]
  workflow_dispatch:
  push: { branches: [ main, master ] }
jobs:
  generate:
    permissions: { contents: write }
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: imteajsajid12
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
          keep_history: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Then go to **Actions → "Generate contribution snake" → Run workflow**.
Finally, uncomment the 🐍 SNAKE image line in the Analytics section above. Done! 🎉

</details>
