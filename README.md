<summary>🛠️ <b>SETUP GUIDE</b> — activate the 🐍 commit-chart snake (click to expand)</summary>

<br>

**Step 1** — In your profile repo (`your-username/your-username`), create the file
`.github/workflows/snake.yml` and paste:

```yaml
name: Generate contribution snake

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [ main, master ]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - name: Build snake from contribution grid
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: imteaj-hossain
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
          keep_history: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**Step 2** — Go to **Actions** tab → run **"Generate contribution snake"** once.

**Step 3** — In this README, find the 🐍 SNAKE HTML comment in the Analytics
section and uncomment the image line. The snake will now crawl across your
commit chart and refresh every 12 hours. 🎉

**Bonus** — Pin your best 6 repositories on your profile so the cards below
the README always show your strongest work.

</details>
